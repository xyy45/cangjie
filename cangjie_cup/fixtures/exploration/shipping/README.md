# 独立规则搜索：运费业务

1. 在“上传文件修复”选择 shipping.cj，导入 goal.txt。
2. 读取函数，选择 shippingFee，导入 tests.json。
3. 在“独立业务规则”导入 oracle.json；核对规则与公开预期后确认。
4. 点击开始。候选公开测试通过后，独立搜索参数边界及组合；发现真实反例时反馈下一轮。

模型可能首轮就修复全部问题，不保证每次都产生多轮。确定性两轮集成验证见 tests/sdk/test_exploration.py，那里模型HTTP响应是测试夹具，仓颉编译、测试和沙箱执行是真实的。

规则表达式是受限记法而非可执行脚本：仅允许已声明参数、Int64/Bool、+ - * // %、比较、and/or/not、`a if condition else b`、min/max/ceil_div。布尔常量为True/False；//及%按仓颉有符号整数向零取整语义计算。禁止任意调用、属性、导入、数组、字符串。ceil_div仅用于非负值和正除数；任何中间Int64溢出均拒绝。

参数域是要探索的输入范围，points给出业务临界点；生成器在域内加入临界点邻近值。seed固定重放，max_cases为16到256。有限搜索与最多两批缩减不证明所有输入正确，也不保证找到全局最小反例。

没有独立规则时仍可使用原公开示例流程。规则与公开例子矛盾时拒绝确认；更改已确认规则需重新上传，不改写历史验证依据。
