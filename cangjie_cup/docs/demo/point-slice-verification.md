# 按行依赖切片验收

日期：2026-10-22。批准范围：新增语句级按行切片，保留变量表；数据来源为 MCP PDG，本地反向遍历；覆盖重新赋值、条件分支和循环，支持结果核对及下载。

## 实现与含义

分析配置版本 5 请求 `sympas_dep_graph(graph_types="Ddg,Cg,Pdg", formats=["dot","svg"])`，继续保留独立变量切片表、DDG、符号结构和调用图 SVG。原分析/样例快照不改写；新样例快照单独保存在 `fixtures/analysis/snapshots-point/`。

读取时核对源码、请求、工具原始响应摘要和已记录 DDG；再独立校验唯一非空 PDG、节点/边上限、唯一节点 ID、源行范围、计数及边端点。DDG 为空或结构无效时，只要工具整体成功且 PDG 自身有效，仍可使用按行切片；非 200 或工具整体失败则拒绝派生。缺失或损坏的 PDG 不会借用 DDG 或变量表冒充按行结果，其余有效工具仍可使用。

算法 `pdg-backward-v1` 以目标行所有显式语句节点为种子，沿输入边遍历数据及控制依赖，以访问集合终止循环。保留所有到达节点及原边，源码高亮仅使用节点的显式行号；不会简单筛选“小于等于目标行”的行，也不会推测没有行号的节点位置。

这是 `LOCAL_PDG_BACKWARD` / `STATEMENT` 作用域的本地派生结果，依赖 MCP 图的质量，不宣称某个变量在某个位置的精确值切片，也不宣称完整过程间/跨函数分析。派生结果不自动进入修复模型上下文或工程验证结论。

## 页面与兼容

有有效 PDG 的新记录默认“按行依赖切片”。输入有效行号、点击源码或带行号的图节点，都在本地即时重算；变量选择仅在“变量切片表”模式显示。没有语句映射的行会清空旧高亮及切片下载链接。旧记录仍可查看变量表或日志恢复结果；重新分析后才能取得 PDG。

快照、会话上传、任务绑定、候选影响绑定分析均提供只读 `point-slice?line=N` 查询；加 `download=1` 导出目标切片证据包，保持原先会话/任务/候选的归属校验。查询只派生结果，不执行新 MCP 请求、不改变冻结记录或审批。

下载增加 `point-slice.json` 和 `point-manifest.json`。后者逐项索引原始文件和派生结果摘要；原 manifest 与工具响应字节保留。结果绑定源码摘要、分析 ID、目标行、种子节点、遍历节点/边、原图工具响应摘要、标准化 PDG 摘要及算法版本。Python 下载实现与浏览器遍历结果有逐字段一致性回归。
