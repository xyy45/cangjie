# 第3阶段：切片驱动定位验收

状态：已完成验收。记录日期：2026-10-24。

## 实现与证据边界

每轮提案前，系统从冻结公开测试或已验证的独立反例重建失败输入、实际值、预期值及需求引用，关联基线函数跨度、返回语句和逐文件PDG后向切片。跨文件调用关系来自受限本地源码索引，标为LOCAL_SOURCE_INDEX；不将其称为MCP跨文件依赖图。位置是累计提案所依赖的不可变基线坐标，失败候选及其树摘要另行绑定。

原测试报告、日志、源文件、复制的MCP原件及定位报告分别核验摘要；日志中的函数、字面量输入和预期值必须与确认测试一致。缺少可信调用映射时保持UNMAPPED；工具空结果或缺少可绑定PDG时保持PARTIAL／UNAVAILABLE。定位只提供静态假设，不构成动态路径或根因证明。

报告以LOCALIZATION_CONTEXT事件持久化，API与归档重新构建核验；模型仅接收最多16KiB的投影，截断显式标明，完整原件仍保留。每轮最多三次模型请求／480秒预算不变。交付包含evidence/localization.json及其引用原件，篡改阻止接受／归档。
